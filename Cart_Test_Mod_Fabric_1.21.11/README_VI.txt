CART TEST MOD - Fabric Minecraft Java 1.21.11

Project source demo: phím V hiện thông báo thử nghiệm.
Không có tự động hóa TNT Minecart/explosions.

BUILD ONLINE (không cần cài JDK trên PC):
1. Tạo GitHub repository mới.
2. Upload toàn bộ nội dung thư mục này (không upload file ZIP nguyên trạng).
3. Mở tab Actions, bật workflow nếu GitHub yêu cầu.
4. Workflow "Build Fabric Mod" tự chạy.
5. Khi hoàn tất: Actions > workflow run mới nhất > Artifacts > cart-test-mod.
   Tải artifact ZIP, bên trong có file .jar.

Lưu ý: GitHub Actions cần internet và có thể cần chấp thuận workflow trên repository.
