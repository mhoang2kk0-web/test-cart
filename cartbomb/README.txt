CART BOMB - Fabric mod cho Minecraft Java 1.21.11
Yeu cau: Java 21, Fabric Loader 0.18.x va Fabric API cho Minecraft 1.21.11.

DAY LA MA NGUON MOD (SOURCE PROJECT), KHONG PHAI FILE JAR DA BUILD.

BUILD FILE JAR:
1. Cai JDK 21.
2. Cai Gradle tuong thich voi Fabric Loom 1.14.
3. Mo terminal tai thu muc cartbomb va chay:
      gradle wrapper
      gradlew build        (Windows)
      ./gradlew build      (macOS/Linux)
4. File mod sau khi build nam tai:
      build/libs/cartbomb-1.0.0.jar
   Khong cai file co hau to -sources.jar.
5. Cai Fabric Loader va Fabric API dung cho Minecraft 1.21.11.
   Chep file JAR vao .minecraft/mods.

CACH DUNG:
- Dat Bow (cung), Rail (duong ray), va TNT Minecart trong Hotbar.
- Cung can co enchant Flame; trong tui can co mui ten.
- Nhin vao mot block hop le, nhan K de chay chuoi thao tac.
- Phim K co the doi trong Options > Controls > Cart Bomb.

LUU Y:
- Mod chay phia client. Server co the tu choi hoac dieu chinh thao tac dat vat pham.
- Can thu nghiem trong the gioi rieng truoc.
